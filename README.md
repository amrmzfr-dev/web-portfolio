# Personal Portfolio

My personal portfolio site. Built with Next.js 15, TypeScript, and Tailwind CSS. Deployed on Vercel.

**Live:** https://web-portfolio-gamma-sooty.vercel.app

## Projects featured

- **Ozone Machine IoT System** — ESP32 firmware + Go backend + React dashboard
- **CCTV API Server** — Python REST bridge over Dahua's C NetSDK, deployed on AWS EC2
- **EV Charger Installation Platform** — End-to-end ops platform built with Go + React + PostgreSQL

## Stack

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS + custom CSS
- **Deployment:** Vercel

## Running locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
